# 快速上手指南

本文档提供最快速的方式开始使用 `cocoapods-binary-cache-mvp` 插件。

## 📦 5 分钟快速开始

### 步骤 1: 安装插件（2 分钟）

```bash
# 进入插件目录
cd /path/to/cocoapods-binary-cache-mvp

# 构建并安装
gem build cocoapods-binary-cache-mvp.gemspec
gem install cocoapods-binary-cache-mvp-0.1.0.gem
```

### 步骤 2: 配置 Podfile（1 分钟）

在你的项目 Podfile 开头添加：

```ruby
plugin 'cocoapods-binary-cache-mvp'

config_binary_cache({
  cache_path: "_Prebuild",
  prebuild_config: "Debug",
  artifact_hash_factors: [:source, :dependencies]
})
```

然后为需要预编译的大型库添加 `:binary => true`：

```ruby
target 'YourApp' do
  use_frameworks!

  # 预编译的库（编译慢的大型库）
  pod 'Alamofire', '~> 5.6', :binary => true
  pod 'RxSwift', '~> 6.5', :binary => true

  # 普通库（编译快的小型库）
  pod 'SwiftyJSON'
end
```

### 步骤 3: 首次预编译（2 分钟）

```bash
# 执行预编译
pod binary prebuild

# 预计等待时间：2-5 分钟（取决于 Pods 数量）
```

你会看到：
```
🚀 CocoaPods Binary Cache MVP
检测到 2 个预编译 Pods: Alamofire, RxSwift
开始预编译...
构建 Alamofire...
构建 RxSwift...
✅ 预编译完成！
```

### 步骤 4: 日常使用（秒级完成）

```bash
# 正常执行 pod install
pod install

# 会自动使用缓存，秒级完成！
```

你会看到：
```
🚀 CocoaPods Binary Cache MVP
检测到 2 个预编译 Pods: Alamofire, RxSwift

缓存验证结果:
✅ 命中缓存 (2):
  - Alamofire (Alamofire-a1b2c3d4e5f6g7h8)
  - RxSwift (RxSwift-x1y2z3a4b5c6d7e8)

❌ 缓存缺失 (0):
```

## 🎯 核心概念速览

### 什么时候需要重新预编译？

**需要重新预编译**（执行 `pod binary prebuild`）：
- ✅ 修改了 Pod 版本（如 `Alamofire '~> 5.6'` 改为 `'~> 5.7'`）
- ✅ 添加了新的 `:binary => true` Pod
- ✅ 修改了 `prebuild_config`（如从 Debug 改为 Release）

**不需要重新预编译**（直接 `pod install`）：
- ✅ 修改了项目代码
- ✅ 修改了未标记 `:binary => true` 的 Pod
- ✅ 修改了 Podfile 中的注释

### 哪些 Pod 适合预编译？

**✅ 推荐预编译**：
- 大型第三方库：Alamofire, RxSwift, AFNetworking, SnapKit
- 稳定的库：版本号长期不变的库
- 编译慢的库：编译时间超过 30 秒

**❌ 不推荐预编译**：
- 小型库：编译时间少于 10 秒
- 频繁修改的库：自己正在开发的模块
- 本地路径 Pod：`:path => '../MyModule'`

## 🛠️ 常用命令

```bash
# 预编译所有标记为 :binary => true 的 Pods
pod binary prebuild

# 使用 Release 配置预编译
pod binary prebuild --config=Release

# 清理缓存后重新预编译
pod binary prebuild --clean

# 日常安装（自动使用缓存）
pod install

# 清理所有缓存
pod binary clean
```

## 📂 生成的目录结构

执行 `pod binary prebuild` 后会生成：

```
YourProject/
├── Podfile
├── _Prebuild/                    # 缓存目录
│   ├── artifacts/                # 压缩的缓存文件
│   │   ├── Alamofire-xxx.zip
│   │   └── RxSwift-xxx.zip
│   └── current/                  # 当前使用的 frameworks
│       ├── Alamofire/
│       │   └── Alamofire.xcframework
│       └── RxSwift/
│           └── RxSwift.xcframework
```

**提示**: 将 `_Prebuild/` 加入 `.gitignore`

## 🔧 故障排查

### 问题 1: `Unknown command: 'binary'`

**原因**: 插件未安装

**解决**:
```bash
gem install cocoapods-binary-cache-mvp-0.1.0.gem
```

### 问题 2: 缓存命中但编译失败

**原因**: 配置变化但缓存未更新

**解决**:
```bash
pod binary clean
pod binary prebuild
```

### 问题 3: 某个 Pod 无法预编译

**原因**: 该 Pod 不支持编译为 framework

**解决**: 移除该 Pod 的 `:binary => true` 标记
```ruby
# 改为普通方式
pod 'SomePod'  # 不加 :binary => true
```
