# 配置指南

## 基本配置

在 Podfile 中使用 `config_binary_cache` DSL 方法进行配置：

```ruby
plugin 'cocoapods-binary-cache-mvp'

config_binary_cache({
  cache_path: "_Prebuild",
  prebuild_config: "Debug",
  artifact_hash_factors: [:source, :dependencies, :build_settings]
})

target 'YourApp' do
  # 标记需要预编译的 Pod
  pod 'Alamofire', :binary => true
  pod 'SnapKit', :binary => true

  # 普通 Pod（不预编译）
  pod 'SwiftyJSON'
end
```

## 配置项详解

### cache_path
- **类型**: String
- **默认值**: `"_Prebuild"`
- **说明**: 缓存根目录，存储所有预编译产物
- **目录结构**:
  ```
  _Prebuild/
  ├── artifacts/        # 缓存的 framework zip 文件
  └── current/          # 当前使用的 frameworks
  ```

### prebuild_config
- **类型**: String
- **默认值**: `"Debug"`
- **可选值**: `"Debug"`, `"Release"`, 或自定义配置
- **说明**: 预编译使用的 Xcode 配置
- **示例**:
  ```ruby
  # 开发环境使用 Debug
  config_binary_cache({
    prebuild_config: "Debug"
  })

  # 生产环境使用 Release
  config_binary_cache({
    prebuild_config: "Release"
  })
  ```

### artifact_hash_factors
- **类型**: Array of Symbols
- **默认值**: `[:source, :dependencies, :build_settings, :compiler_flags, :deployment_target]`
- **可选因子**:
  - `:source` - Pod 源代码版本（通过 Podfile.lock 的 SPEC CHECKSUMS）
  - `:dependencies` - 依赖的其他 Pods 及其版本
  - `:build_settings` - Xcode 构建设置
  - `:compiler_flags` - 编译器参数
  - `:deployment_target` - 部署目标版本

- **说明**: 决定 Artifact ID 的计算因子。只有这些因子都不变时，才会命中缓存
- **示例**:
  ```ruby
  # 最小化配置：仅考虑源码和依赖
  config_binary_cache({
    artifact_hash_factors: [:source, :dependencies]
  })

  # 完整配置：考虑所有因子（更精确但缓存命中率更低）
  config_binary_cache({
    artifact_hash_factors: [:source, :dependencies, :build_settings, :compiler_flags, :deployment_target]
  })
  ```

### prebuild_sandbox_path
- **类型**: String
- **默认值**: `"#{cache_path}/Pods"`
- **说明**: 预编译沙盒目录，用于执行 pod install 和构建
- **一般无需修改**

### validate_prebuilt_settings
- **类型**: Boolean
- **默认值**: `false`
- **说明**: 是否验证预编译设置的一致性
- **建议**: 生产环境开启，开发环境关闭

## 标记预编译 Pod

在 Podfile 中使用 `:binary => true` 标记需要预编译的 Pod：

```ruby
target 'YourApp' do
  # 方式 1：直接标记
  pod 'Alamofire', :binary => true

  # 方式 2：指定版本
  pod 'SnapKit', '~> 5.0', :binary => true

  # 方式 3：本地 Pod（开发 Pod）
  pod 'MyLocalPod', :path => '../MyLocalPod', :binary => true
end
```

## 配置示例

### 开发环境配置
```ruby
plugin 'cocoapods-binary-cache-mvp'

config_binary_cache({
  cache_path: "_Prebuild",
  prebuild_config: "Debug",
  artifact_hash_factors: [:source, :dependencies],
  validate_prebuilt_settings: false
})

target 'MyApp' do
  # 只预编译大型、稳定的第三方库
  pod 'Alamofire', :binary => true
  pod 'AFNetworking', :binary => true

  # 频繁修改的库不预编译
  pod 'MyFeatureModule'
end
```

### CI/CD 环境配置
```ruby
plugin 'cocoapods-binary-cache-mvp'

config_binary_cache({
  cache_path: "_Prebuild",
  prebuild_config: "Release",
  artifact_hash_factors: [:source, :dependencies, :build_settings],
  validate_prebuilt_settings: true
})

target 'MyApp' do
  # 预编译所有稳定的第三方库
  pod 'Alamofire', :binary => true
  pod 'SnapKit', :binary => true
  pod 'RxSwift', :binary => true
  # ... 更多第三方库
end
```

## 常见问题

### 1. 如何选择 artifact_hash_factors？

**建议策略**:
- **开发环境**: `[:source, :dependencies]` - 快速迭代，更高缓存命中率
- **CI 环境**: `[:source, :dependencies, :build_settings]` - 平衡准确性和性能
- **生产构建**: 所有因子 - 确保二进制完全一致

### 2. 缓存目录占用空间过大怎么办？

定期清理缓存：
```bash
pod binary clean
```

或手动删除：
```bash
rm -rf _Prebuild/artifacts/*
```

### 3. 修改了 Pod 代码但缓存没更新？

检查：
1. 是否更新了版本号（修改 Podfile 中的版本）
2. 是否执行了 `pod install`（会更新 Podfile.lock）
3. artifact_hash_factors 是否包含 :source 因子

### 4. 预编译失败怎么办？

检查：
1. Pod 是否支持编译为 framework（某些 Pod 不支持）
2. prebuild_config 配置是否正确
3. 查看详细错误日志：`pod binary prebuild --verbose`

### 5. 某些 Pod 不想预编译？

不添加 `:binary => true` 标记即可：
```ruby
# 这个 Pod 会正常编译（不使用缓存）
pod 'SomePod'

# 这个 Pod 会使用预编译缓存
pod 'AnotherPod', :binary => true
```
