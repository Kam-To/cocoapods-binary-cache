# 工作原理

## 核心概念

### Artifact（制品）
每个预编译的 Pod 对应一个 Artifact，包含：
- **name**: Pod 名称
- **version**: Pod 版本
- **artifact_id**: 唯一标识符（基于哈希计算）
- **hash_data**: 用于计算哈希的数据

**Artifact ID 格式**: `{PodName}-{Hash前16位}`
例如: `Alamofire-a1b2c3d4e5f6g7h8`

### Artifact ID 计算

```ruby
# 伪代码示例
hash_components = []
hash_components << pod_checksum           # 来自 Podfile.lock 的 SPEC CHECKSUMS
hash_components << dependencies_info      # 依赖的 Pods 及版本
hash_components << build_settings         # Xcode 构建设置

hash_string = hash_components.join('-')
hash_value = SHA256(hash_string)[0..15]   # 取前16位
artifact_id = "#{pod_name}-#{hash_value}"
```

**重要**: 只有所有 hash_factors 都不变时，Artifact ID 才保持不变，才能命中缓存。

## 完整工作流程

### 1. 开发阶段：执行 pod install

```
用户执行: pod install
    ↓
插件 pre_install 钩子触发
    ↓
1. 检测预编译 Pods（标记了 :binary => true 的 Pod）
    ↓
2. 缓存验证
   - 读取 Podfile.lock
   - 为每个预编译 Pod 计算 Artifact ID
   - 检查缓存目录是否存在对应的 .zip 文件
   - 分类结果: [命中] 和 [缺失]
    ↓
3. 使用缓存
   - 解压缓存的 frameworks 到 _Prebuild/current/
   - 链接到主项目
    ↓
继续正常的 pod install 流程
```

**关键点**:
- 开发阶段 **不会执行预编译**，只会使用已有缓存
- 如果缓存缺失，Pod 将使用源码编译（正常流程）

### 2. 预编译阶段：执行 pod binary prebuild

```
用户执行: pod binary prebuild
    ↓
1. 触发 pod install（带 prebuild_job 标记）
    ↓
2. pre_install 钩子检测到 prebuild_job=true
    ↓
3. 执行预编译流程
   ├─ 创建预编译沙盒
   ├─ 在沙盒中执行 pod install
   └─ 使用 xcodebuild 构建每个 Pod
       ├─ 为 iOS 模拟器构建
       ├─ 为 iOS 真机构建
       └─ 合并为 xcframework（或 framework）
    ↓
4. 发布到缓存
   - 将构建的 framework 打包为 .zip
   - 移动到 _Prebuild/artifacts/{artifact_id}.zip
    ↓
5. 清理旧缓存（可选）
```

## 缓存验证详解

### 验证流程

```ruby
# 1. 读取 Podfile.lock
lockfile = Pod::Lockfile.from_file('Podfile.lock')

# 2. 为每个预编译 Pod 收集哈希数据
prebuilt_pods.each do |pod_name|
  hash_data = {}

  # Factor: source (来自 SPEC CHECKSUMS)
  hash_data[:source] = lockfile.checksum(pod_name)

  # Factor: dependencies
  dependencies = lockfile.dependencies_of(pod_name)
  hash_data[:dependencies] = dependencies.map { |d| "#{d.name}-#{d.version}" }.sort.join(',')

  # Factor: build_settings
  # （从 target 定义中读取）
  hash_data[:build_settings] = target.build_settings.to_s

  # ... 其他 factors

  # 3. 计算 Artifact ID
  artifact = Artifact.new(pod_name, version, hash_data)
  artifact_id = artifact.calculate_artifact_id

  # 4. 检查缓存是否存在
  cache_file = "_Prebuild/artifacts/#{artifact_id}.zip"
  if File.exist?(cache_file)
    hits << pod_name
  else
    misses << pod_name
  end
end
```

## Framework 构建详解

### 构建流程

```bash
# 1. 为模拟器构建
xcodebuild build \
  -project Pods.xcodeproj \
  -scheme Alamofire \
  -configuration Debug \
  -sdk iphonesimulator \
  -destination "generic/platform=iOS Simulator" \
  BUILD_DIR="$BUILD_DIR" \
  CONFIGURATION_BUILD_DIR="$BUILD_DIR/iphoneos"

# 2. 为真机构建
xcodebuild build \
  -project Pods.xcodeproj \
  -scheme Alamofire \
  -configuration Debug \
  -sdk iphoneos \
  -destination "generic/platform=iOS" \
  BUILD_DIR="$BUILD_DIR" \
  CONFIGURATION_BUILD_DIR="$BUILD_DIR/iphonesimulator"

# 3. 创建 xcframework
xcodebuild -create-xcframework \
  -framework "$BUILD_DIR/iphoneos/Alamofire.framework" \
  -framework "$BUILD_DIR/iphonesimulator/Alamofire.framework" \
  -output "_Prebuild/current/Alamofire/Alamofire.xcframework"

# 4. 压缩为 zip
cd _Prebuild/current/Alamofire
zip -r "../../../artifacts/Alamofire-a1b2c3d4e5f6g7h8.zip" .
```

### XCFramework vs Framework

| 特性 | Framework | XCFramework |
|------|-----------|-------------|
| 多架构支持 | 需要 lipo 合并 | 原生支持 |
| 模拟器+真机 | 需要手动处理 | 自动处理 |
| 推荐使用 | ❌ 旧项目 | ✅ 新项目 |

本插件优先生成 XCFramework，回退到 Framework。

## 缓存管理

### 目录结构

```
_Prebuild/
├── artifacts/                    # 压缩的缓存文件
│   ├── Alamofire-a1b2c3d4.zip   # Artifact ID 作为文件名
│   ├── SnapKit-x1y2z3a4.zip
│   └── RxSwift-m1n2o3p4.zip
├── current/                      # 当前使用的 frameworks
│   ├── Alamofire/
│   │   └── Alamofire.xcframework
│   ├── SnapKit/
│   │   └── SnapKit.xcframework
│   └── RxSwift/
│       └── RxSwift.xcframework
└── Pods/                         # 预编译沙盒（仅在预编译时使用）
```

### 缓存发布流程

```ruby
# 1. 构建完成后
framework_path = "_Prebuild/current/Alamofire/Alamofire.xcframework"

# 2. 创建 zip
artifact_id = "Alamofire-a1b2c3d4e5f6g7h8"
zip_path = "_Prebuild/artifacts/#{artifact_id}.zip"

Zip::File.open(zip_path, Zip::File::CREATE) do |zipfile|
  Dir.glob(framework_path + "/**/*").each do |file|
    zipfile.add(file.sub("#{framework_path}/", ""), file)
  end
end

# 3. 记录元数据（可选）
metadata = {
  pod_name: "Alamofire",
  version: "5.6.0",
  artifact_id: artifact_id,
  created_at: Time.now,
  size: File.size(zip_path)
}
```

### 缓存获取流程

```ruby
# 1. 查找缓存文件
artifact_id = "Alamofire-a1b2c3d4e5f6g7h8"
zip_path = "_Prebuild/artifacts/#{artifact_id}.zip"

return false unless File.exist?(zip_path)

# 2. 解压到 current 目录
dest_path = "_Prebuild/current/Alamofire"
FileUtils.mkdir_p(dest_path)

Zip::File.open(zip_path) do |zipfile|
  zipfile.each do |entry|
    file_path = File.join(dest_path, entry.name)
    FileUtils.mkdir_p(File.dirname(file_path))
    entry.extract(file_path)
  end
end

# 3. 链接到主项目
# （由 CocoaPods 自动处理）
```

## 性能优化

### 1. 选择性预编译
只预编译大型、稳定的库：
```ruby
# ✅ 适合预编译：大型、稳定、编译慢
pod 'Alamofire', :binary => true
pod 'RxSwift', :binary => true

# ❌ 不适合预编译：小型、频繁修改
pod 'MyUtils'  # 不加 :binary => true
```

### 2. 调整 hash_factors
减少 factors 可提高缓存命中率：
```ruby
# 开发环境：最小化 factors
config_binary_cache({
  artifact_hash_factors: [:source, :dependencies]
})

# CI 环境：平衡准确性和性能
config_binary_cache({
  artifact_hash_factors: [:source, :dependencies, :build_settings]
})
```

### 3. 并行构建
在 CI 环境中并行预编译多个 Pods：
```bash
# 将 Pods 分组，使用多个 CI job 并行构建
# Job 1: pod binary prebuild --targets=Alamofire,SnapKit
# Job 2: pod binary prebuild --targets=RxSwift,Kingfisher
```

## 故障排查

### 缓存命中但编译失败

**原因**: Artifact ID 相同但实际二进制不兼容

**解决**:
1. 增加 hash_factors（如添加 :build_settings）
2. 清理缓存: `pod binary clean`
3. 重新预编译: `pod binary prebuild`

### 预编译成功但主项目链接失败

**原因**: Framework 路径或架构不匹配

**检查**:
1. 验证 xcframework 包含所需架构
   ```bash
   xcodebuild -checkFirstLaunchStatus -xcframework _Prebuild/current/Alamofire/Alamofire.xcframework
   ```
2. 检查 Xcode 项目的架构设置

### 缓存目录损坏

**症状**: 解压失败、文件缺失

**解决**:
```bash
# 清理所有缓存
rm -rf _Prebuild/artifacts/*
rm -rf _Prebuild/current/*

# 重新预编译
pod binary prebuild
```
